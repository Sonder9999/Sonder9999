# Bundled fonts

These fonts are vendored so that the contribution GIFs render identically on
Windows, Linux and GitHub Actions.  They are not loaded from the system.

| File | Family | Weight | Source |
|---|---|---|---|
| `NotoSans-Regular.ttf` | Noto Sans | 400 | https://github.com/googlefonts/noto-fonts |
| `NotoSans-Bold.ttf` | Noto Sans | 700 | https://github.com/googlefonts/noto-fonts |
| `NotoSans-ExtraBold.ttf` | Noto Sans | 800 | https://github.com/googlefonts/noto-fonts |
| `JetBrainsMono-Regular.ttf` | JetBrains Mono | 400 | https://github.com/JetBrains/JetBrainsMono |
| `JetBrainsMono-Bold.ttf` | JetBrains Mono | 700 | https://github.com/JetBrains/JetBrainsMono |
